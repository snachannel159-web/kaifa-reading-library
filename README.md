# مكتبة كيف؟ للقراءة

مستودع تجهيز نسخة GitHub Pages للمكتبة العربية.

## النسخة المجهزة
- 3 كتب نصية، وكتاب صوتي، و12 كتابًا مرئيًا.
- أحدث الأغلفة، وتقليب الصفحات والفهارس وروابط المشاهدة.
- واجهة القراءة معدة للمسار `/kaifa-reading-library/`.
- إدارة الحساب والنشر تفتح الخدمة الأصلية؛ GitHub Pages يستضيف نسخة القراءة فقط.

## الحالة الحالية
المستودع خاص. تجهيز الحزمة وفحص المسارات مكتملان، لكن رفع الحزمة وتثبيتها والنشر العام لم تكتمل بعد، وتنتظر الموافقة الصريحة على إتاحة ملفات المكتبة هنا.

لا توجد بيانات اعتماد للخادم ضمن حزمة القراءة.
