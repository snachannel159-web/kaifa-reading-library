# مكتبة كيف؟ للقراءة
نسخة GitHub Pages من المكتبة العربية: 3 كتب نصية، كتاب صوتي، و12 كتابًا مرئيًا.

## المحتوى
آخر الأغلفة المعتمدة، قراءة باتجاه عربي، وتقليب بالأسهم والسحب، مع الفهارس وروابط الصفحات والصوتيات.
الكتب المرئية تحتوي 1074 مقطعًا عبر Google Drive، وتظل صلاحيات Drive الأصلية مطبقة.

## الحساب والنشر
تسجيل الدخول ونشر الكتب وإدارتها يفتح الخدمة الأصلية، ولا يعمل كخادم داخل GitHub Pages.
الكتب المنشورة لاحقًا من المستخدمين تحتاج تحديث نسخة التصدير كي تظهر هنا.

## استخراج ملفات الموقع
```sh
cat library-site.tar.gz.part-* > library-site.tar.gz
sha256sum -c SHA256SUMS
mkdir -p site
tar -xzf library-site.tar.gz -C site
```
الحزمة تضم ملفات الواجهة والمحتوى فقط؛ لا تضم بيانات اعتماد أو أسرار الخادم.

## النشر
المكتبة منشورة على: https://snachannel159-web.github.io/kaifa-reading-library/

المستودع Public، ومصدر GitHub Pages هو GitHub Actions. لتحديث النشر بعد تعديل الحزمة، شغّل **Publish Kaifa Library** يدويًا من Actions. يفحص سير العمل سلامة الحزمة ثم ينشر ملفات الموقع.
